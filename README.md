# Floreria
# 🌸 Florería Julia Rosa

Este es nuestro proyecto de sitio web para la asignatura de Desarrollo Web. Es una tienda online para la florería **Julia Rosa** donde los usuarios pueden ver el catálogo de flores, agregar productos al carrito y registrarse.

---

## Herramientas Usadas

* **HTML:** Para crear la estructura de las páginas.
* **CSS y Bootstrap:** Para darle diseño, colores y que se vea bien en celulares y computadores.
* **JavaScript:** Para mostrar los productos de forma dinámica.

---

## Páginas del Sitio

* `Principal.html`: Página de inicio con promociones y productos recomendados.
* `nosotros.html`: Historia de la tienda, Misión, Visión e integrantes del grupo.
* `Inventario.html`: Catálogo con todas las flores disponibles.
* `producto.html`: Detalle de cada producto.
* `Registro.html`: Formulario para iniciar sesión o registrarse.
* `carrito de compra.html`: Carrito de compras.
* `contacto.html`: Formulario para enviar mensajes a la tienda.
